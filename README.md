# 💖 Friendship Day Website

A modern and interactive Friendship Day website built using **HTML**, **CSS**, and **JavaScript**. The project is designed to celebrate friendship through a clean user interface, smooth animations, personalized messages, and a responsive layout.

---

## ✨ Features

- 🎨 Modern and responsive user interface
- 💌 Personalized friendship letter popups
- 🌸 Beautiful gradient and glassmorphism-inspired design
- ❤️ Animated loading screen
- 📖 Friendship story section
- 🤝 Friendship promises section
- 🎁 Interactive final surprise message
- 📱 Fully responsive across different screen sizes
- ⚡ Smooth scrolling and interactive animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/friendship-day-website.git
```

2. Open the project folder.

3. Run `index.html` in your preferred web browser.

No additional setup or dependencies are required.
